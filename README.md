## 1. О чём исследование

Когда я выбираю товары в интернет-магазине, иногда достаточно открыть пару страниц, чтобы сделать заказ. А иногда можно просмотреть десятки товаров и ничего не купить.

Мне стало интересно, есть ли статистическая связь между количеством просмотренных товарных страниц и фактом покупки.

Для исследования я взяла датасет [Online Shoppers Purchasing Intention](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset) из UCI Machine Learning Repository.

В нём собраны данные о **12 330 пользовательских сессиях** интернет-магазина. Каждая строка соответствует одной сессии.

Я рассмотрела две случайные величины:

| Величина | Столбец | Описание |
|:--|:--|:--|
| $X$ | `ProductRelated` | Количество просмотренных товарных страниц |
| $Y$ | `Revenue` | Факт покупки: 0 — нет, 1 — да |

$X$ — дискретная случайная величина, принимающая неотрицательные целые значения.

$Y$ — случайная величина с распределением Бернулли.

Обе величины относятся к одной пользовательской сессии, поэтому можно исследовать их статистическую зависимость.

## 2. Почему эти величины случайные

До начала пользовательской сессии нельзя точно определить, сколько страниц человек просмотрит и завершится ли его посещение покупкой.

Поведение зависит от множества факторов: цели визита, интереса к товарам, цен, ассортимента и других обстоятельств.

В ноутбуке я рассматриваю сессии как исходы вероятностного эксперимента. Для каждой величины задаётся отображение из пространства исходов в множество числовых значений и проверяется измеримость.

Отдельно анализируется эмпирическая изменчивость данных. Она показывает, что наблюдаемые значения различаются даже внутри групп с одинаковыми доступными характеристиками.

Это не означает, что случайность можно доказать только по таблице наблюдений. Вероятностная модель нужна для описания неопределённости поведения покупателей.

## 3. Первичный анализ данных

В работе я изучила распределения обеих величин:

- основные описательные статистики;
- частоты и относительные частоты;
- среднее значение и медиану;
- дисперсию и стандартное отклонение;
- асимметрию распределения;
- выбросы;
- графики распределений.

Основные результаты:

| Показатель | Значение |
|:--|--:|
| Количество сессий | 12 330 |
| Среднее число просмотренных товарных страниц | 31,73 |
| Медианное число просмотренных товарных страниц | 18 |
| Сессии с покупкой | 1 908 |
| Доля сессий с покупкой | 15,47% |

Среднее количество просмотров заметно превышает медиану. Это связано с правосторонней асимметрией распределения: большинство пользователей просматривают относительно немного страниц, но встречаются сессии с очень большим числом просмотров.

Покупкой заканчивается примерно каждая шестая-седьмая сессия.

## 4. Проверка зависимости

Основной вопрос исследования: **связаны ли число просмотренных страниц и факт покупки?**

Для проверки я разделила количество просмотров на группы и построила таблицу сопряжённости с фактом покупки.

Проверялись две гипотезы:

- $H_0$: группа по количеству просмотров и факт покупки независимы.
- $H_1$: между ними существует статистическая зависимость.

Для проверки использован критерий согласия Пирсона $\chi^2$ для таблицы сопряжённости.

Результаты:

| Показатель | Значение |
|:--|--:|
| Статистика $\chi^2$ | 468,93 |
| Степени свободы | 5 |
| p-value | $4,05 \cdot 10^{-99}$ |
| V Крамера | 0,195 |
| Уровень значимости $\alpha$ | 0,05 |

Полученное p-value значительно меньше выбранного уровня значимости.

**Нулевая гипотеза отвергается:** в исследуемых данных количество просмотренных страниц статистически связано с фактом покупки.

При этом значение V Крамера показывает, что связь не является очень сильной.

Важно учитывать, что статистическая зависимость не равна причинно-следственной. По этим данным нельзя утверждать, что дополнительные просмотры сами по себе повышают вероятность покупки.

## 6. Генератор случайных чисел

Для интерактивной части я выбрала величину $X$ — количество просмотренных товарных страниц.

У неё дискретное распределение с заметной асимметрией. Поэтому для генерации я использовала **метод обратной функции распределения (квантильное преобразование)**.

Пусть $F_X(x)$ — функция распределения случайной величины $X$, а $U$ равномерно распределена на интервале $(0,1)$.

Тогда случайную величину с нужным распределением можно получить по формуле:

$$
X = F_X^{-1}(U),
$$

где для дискретного случая обобщённая обратная функция определяется как

$$
F_X^{-1}(u)=\inf\{x:F_X(x)\geq u\}.
$$

В генераторе используется эмпирическое распределение, рассчитанное по исходному датасету.

Проверка включает:

- сравнение средних значений;
- сравнение дисперсий;
- сопоставление эмпирических функций распределения;
- сравнение частот;
- оценку максимального расхождения между функциями распределения.

Для анализа расхождений также используется неравенство Дворецкого — Кифера — Вольфовица (DKW).

## 7. Итоги

В начале работы я предполагала, что пользователи, которые просматривают больше товаров, могут чаще совершать покупки.

Анализ показал, что между количеством просмотров и фактом покупки действительно есть статистическая связь.

Однако число просмотров само по себе не позволяет надёжно предсказать покупку. На решение пользователя влияют и другие факторы, которых в этом исследовании я подробно не касалась.

Также я убедилась, что случайную величину можно не только описать с помощью распределения, но и построить на его основе генератор.

Метод обратной функции оказался удобным для дискретных данных: он позволяет воспроизводить наблюдаемое распределение без подбора сложной параметрической модели.

Главное ограничение исследования заключается в том, что выводы получены по конкретному датасету. Переносить их на все интернет-магазины без дополнительных данных нельзя.
